# confluence-md

Confluence 본문을 LLM 컨텍스트에 적합한 Markdown으로 추출하는 Chrome 확장입니다. 페이지에서 필요한 본문만 로컬에서 변환해 파일로 내려받습니다.

## 설치

1. `git clone https://github.com/lisyoen/confluence-md.git`
2. Chrome에서 `chrome://extensions`를 엽니다.
3. **개발자 모드**를 켭니다.
4. **압축해제된 확장 프로그램을 로드**를 클릭합니다.
5. clone한 저장소의 `publish/extension` 폴더를 선택합니다.

## 사용법

Confluence 페이지에서 툴바의 확장 아이콘을 클릭하면 `{페이지제목}.md` 파일이 자동으로 다운로드됩니다.

## 업데이트

저장소에서 `git pull`을 실행한 뒤 `chrome://extensions`에서 Confluence Markdown 확장의 새로고침(↻) 버튼을 클릭합니다.

## 동작 방식

- 페이지의 `#main-content` 영역만 파싱합니다.
- 전 과정을 브라우저 안에서 로컬로 변환합니다.
- 페이지 내용을 외부 서버로 전송하지 않습니다.
- 이미지와 첨부 파일은 LLM 컨텍스트에 불필요하므로 의도적으로 제외합니다.

## 변환 지원 범위

| 항목 | 지원 내용 |
| --- | --- |
| 제목 | 문서 제목과 단계별 제목 |
| 표 | GFM 표, 병합 셀 근사, 셀 여러 줄 한 줄화 |
| 코드블록 | 언어가 있는 코드와 일반 코드 |
| 작업목록 | 체크·미체크 및 중첩 목록 |
| 펼치기/확장 | 닫힌 영역을 포함한 본문 |
| 상태 매크로 | 상태 텍스트 |
| 링크 | 상대경로를 포함한 문서 링크 |
| 이미지·첨부·이모티콘 | 제외 |

## 개발

```bash
npm install
npm test
npm run publish
```

`npm run publish -- "변경 요약"`처럼 한 줄 변경 요약을 전달할 수 있습니다.

## 주의

이 확장은 manifest에 지정된 대상 호스트와 연결되는 사내망 환경에서만 동작합니다. 생성된 Markdown에도 문서 내용이 포함되므로 외부 반출이나 공유가 발생하지 않도록 사용자가 산출물을 주의해서 취급해야 합니다.
